Frequently Asked Questions

How can I submit an event?

Complete the event submission form and select the Submit Event button.

How do I reserve a seat?

Search for an event, select RSVP on its card, and complete the sign-up form.

Where does event data come from?

The cards are read from the single events.json data file through the Node.js HTTP server. Event creation and RSVP updates are saved to that file.

About the Event Board

IIIT Vadodara uses this board to share campus activities.

Each event card is created dynamically using JavaScript DOM methods after the server reads event records from events.json.

Event information should be checked before attending.
